# Public Case Study Scope

This repository is documentation for the engineering behind SAEI.

## Included

- RAG architecture
- generalized document-ingestion design
- retrieval and citation concepts
- tenant-isolation principles
- risk-analysis structures
- sanitized pseudocode
- system diagrams

## Not included

- production application source code
- customer documents
- private legal corpora
- credentials
- proprietary prompts
- private ranking/retrieval configuration
- confidential business logic
- personally identifiable customer data

The examples are intentionally generalized so the architecture can be discussed without exposing protected product assets.
